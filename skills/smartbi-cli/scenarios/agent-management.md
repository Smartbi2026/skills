# 智能体与工具管理

## 触发

用户明确要求查看、创建或修改智能体工作流，或维护 OpenAPI 工具 Provider 时使用。本场景管理配置，不负责运行普通白泽问数；查询失败不触发配置修改。

## 执行

1. 核实目标环境、资源、操作范围及授权；优先复用当前 SDK 已注册的管理接口，未知时只在对应业务域发现操作。
2. SDK 缺少目标能力时，只有当前部署的内部接口与认证方式已确认，才使用本模块辅助脚本。不能用猜测的路径、其他环境的会话或浏览器凭据替代。
3. 工作流按[智能体工作流](../references/agent-management/agent-workflows.md)读取、预览、创建或修改；Provider 按[工具管理](../references/agent-management/tool-providers.md)列举、读取或解析。只加载所需分支。
4. 写操作按用户授权执行；更新保留未知字段，提交前备份并检查版本哈希，提交后核对字段。配置保存成功不等于已发布或可运行。
5. 用户要求验证运行效果时，由主入口组合已保留的白泽模块，新建独立测试会话并检查结果。未包含运行模块时只报告配置回读结论，不声称执行已验证。

## 边界与依赖

`scripts/agent-management/smartbi_internal.py` 保留工作流读取、创建、更新和 Provider 列举、读取、解析六个命令。创建和更新默认预览，仅显式 `--apply` 提交；不自动重试写操作。内部接口不属于稳定公开 SDK 承诺，缺少契约或权限时说明限制，不进入普通取数的失败恢复链。

连接选择与授权复用公共规则；内部接口的 Cookie 或其他认证头仅从用户指定环境变量读取，不能假定 CLI 的个人访问令牌可直接替代。脚本、请求和备份使用绝对路径，输出放用户工作目录，不写入 Skill。
