# 已有报表问数

适用于查询已有 SmartBI 报表、工作表或组件的数据。生成本地报告、创建或修改服务端报表分别遵循数据与洞察路由、资源操作流程，不因出现“报表”二字进入本分支。

报表资源不只指名称含“报表”的对象。用户明确基于电子表格、Web 电子表格、仪表盘、即席查询或透视分析等已有资源问数，或只提供名称、别名、ID 而目录核实其 `type` 为报表类型时，均进入本路径。常见类型包括 `SPREADSHEET_REPORT`、`WEB_SPREADSHEET_REPORT`、`SMARTBIX_PAGE`、`DETAILED_QUERY`、`COMBINED_QUERY`、`AD_HOC_ANALYSIS`、`INSIGHT`、`SIMPLE_REPORT`；以当前环境目录返回的实际类型及接口契约为准，不仅凭名称猜类型。用户要求创建、修改、发布报表时仍走相应资源操作路径。

## 最小路径

按名称/ID/链接或业务需求定位报表 → 通过接口获取必要定义、参数和默认值 → 对齐问句与有效筛选 → 读取或导出报表结果 → 校验 → 回答。

外部智能体没有页面注入的报表列表或浏览器当前筛选状态。报表尚未定位或范围有歧义时按 `query-routing.md` 做资源发现与范围判断；已知报表和有效参数可直接执行本文件的最小路径。报表链接用于定位，不证明已取得当前页面参数。用户要求复现“当前页面”但缺少筛选、联动或钻取状态时，只补问影响答案的缺项；不能拿报表默认结果冒充页面当前结果。默认值只能来自已核实的接口定义或明确提供的信息。

- 通过当前环境的 CLI 发现、describe 和文档核实只读报表查询/导出能力；若能保持报表口径并完整回答，直接调用。需要服务端检索或内部工具能力时，按目标部署实际可访问的报表取数 Skill 与会话契约核实后使用，见 `sessions-and-logs.md`；不要假定其固定名称或已经对外开放。不要求先试错直接接口，也不因报表问题简单就套用模型 MQL。
- 用户明确不经过服务端 AI 时遵循该要求；无已验证的直接能力则说明限制，不能悄悄创建白泽会话。内置 Skill 的存在不证明其接口已向 SDK 暴露。
- 核实报表 ID、真实资源类型和路径；同名报表不能直接选第一项。仅获取回答所需的工作表、组件、参数、默认值、单位及计算口径。已有充分上下文就复用，不每轮重新导出或读取全部定义，不建立持久化缓存。
- 报表绑定模型不证明模型查询与报表等价。只有筛选、计算、权限、时间范围和粒度均有充分依据时才能评估回溯模型；不能将报表 ID 当成模型 ID，也不能把原始模型值冒充报表显示值。
- 若元数据 `params=[]` 且默认导出只有表头，当前报表直读路径尚未取得业务记录；不要据此推断空数据的原因，也不要用未定义的表头/字段名猜 `paramsInfo` 参数键反复导出。`columns[].id` 如含模型 ID，可作为定位底层模型的线索；仅在核实报表筛选、计算、权限、时间与粒度等口径可对齐后，才可转模型查询并明确标为模型结果。若无法证明等价，应说明报表结果尚不可得，而不是把模型结果称为该报表结果。

## 参数与问句对齐

- 区分报表参数、组件展示字段和计算指标；参数键必须来自实际参数定义，不能将任意表头作为参数。关键词或语义检索命中只帮助定位，不证明字段或数据已存在。
- 用户明确值覆盖同名默认值，保留本任务已确认且仍适用的其他参数；不跨报表继承、不擅自应用用户要求取消的条件。区分用户指定、本任务前次已确认、接口返回的报表默认及尚未确认的值，不推断浏览器当前选择。省略参数可能启用默认筛选，不能声称“全部”。请求参数仅证明已发送，实际生效仍需响应元数据或结果证据。
- 必填参数须有有效值或已确认的可用默认值；非空参数对象不证明所有必填项齐全。只澄清影响答案的缺项或歧义，不反复询问已确认默认值。
- 按参数类型处理：输入值遵循输入组件语义；日期按声明格式、用户时区和明确的时间范围转换；选择参数核实显示值与实际值的映射。检索候选只是子集，不能当作全量枚举或据未命中断言值不存在。
- 多选编码、空字符串、清空筛选与省略值的含义由当前契约确定，不通用化“逗号连接”或“空字符串代表全部”。同名或近义参数不自动全部赋同值；须确认各组件绑定和作用域。
- 多报表分别核对参数和指标口径；不能仅因参数较少选择报表。合并结果前核对连接键、粒度、重叠范围及可加性。不支持多选时，只有分次查询保持原语义才可合并，不能拼接后重复计算总计、比率或去重数。

## 结果与交付

- 优先使用能满足问句的只读结果；若当前能力仅支持导出，就导出并回读。文件格式依接口能力及实际内容确定，不强制 CSV，不因文件格式推定全量。
- 检查 HTTP 与业务状态及实际文件内容；JSON/HTML 错误响应不能当作 Excel/CSV。核对查询范围、截断、相关工作表和组件；导出“全部行”参数只是请求意图，不证明服务端无上限。
- 统计时区分“文件可读”“存在表头”“存在业务记录”。只有表头的工作表不能计为已取到该组件数据；图像页也不能按空单元格认定无内容。参数覆盖后文件或单元格变化只证明输出发生变化，还需核对实际筛选、期间标签及对应业务数据，才能宣称条件生效、数值正确。
- 参数变更后，若数据行的原始期间与展示期间冲突，或当期值为空但报表显示下降100%，应区分“报表显示值”和“可验证的业务结论”。保留空值及冲突位置，不把空值当零、不自行改标签或改公式修正报表；只交付能证实的部分，明确受影响结论暂不可确认。差额/比率复算一致仅证明导出数据内部算术一致，不能证明筛选或源数据正确。
- 多级表头、合并单元格、明细、小计及总计应分别识别。填充合并单元格不能复制金额后求和；仅在证实为纯图片且不含所需数据时跳过工作表，不能固定跳过第一页。
- 某些电子表格元数据可能不列出 `columns` 或 `params`；这不妨碍按已核实的导出契约读取默认结果，但不能据此推断没有报表筛选。若同一次导出同时包含统计页与对应明细页，且指标、筛选、范围和聚合方式一致，可用明细独立复算统计值并核对差异；不对去重数、比率、非可加指标或范围不同的页签强制求和对账。
- 使用支持真实格式的读取器；XLS 与 XLSX 不能互换。公式缓存可能缺失或过期，不能把空缓存当零；保留原始值、编码、单位和显示精度，区分报表显示值与重新计算值。
- 按问句核对指标、筛选、时间和计算口径。筛选参数不一定出现在导出列中，应从有效参数/执行证据核验，不能因没有该列而认定未筛选。条件生效无法确认时明确限制，不以导出成功宣称查询完成。
- 交付业务答案、必要的有效筛选和报表/工作表/组件来源；计算值注明公式及所依据数据。文件按用户需要或结果规模提供，不强制附加 CSV 或内部校验清单。只改变展示的追问复用本轮适用的完整数据，条件或数据新鲜度变化时再查询。

## 兼容性边界

### 已验证的 SDK 入口

以下内容是可执行示例，不是跨版本固定协议。调用时以目标环境当前 `describe` 返回的契约为准；本任务已经核实且环境和版本未变化时直接复用，不重复探测：

- `report.getReportMetadata`：当前契约仅要求 `resourceId`，已知报表 ID 时优先传 `{"resourceId":"<报表ID>"}`；接口可自行识别类型，并在结果的 `type` 中返回实际类型。`resourceType` 是可选参数，不要为了填它而预先读取目录扩展信息。实际字段集合可能为 `columns` 而非示例中的 `fields`；参数可能未返回默认值或备选值，不能解释为无限制。同名指标应结合组件身份和聚合方式识别，不能合并不同组件的 SUM、AVG。
- `report.exportReport`：当 `describe` 显示路径参数为 `resId` 时使用 `--path resId=<报表ID>`；二进制响应通过 `--output <文件路径>` 保存。只有契约明确 `exportRows=0` 或省略表示全部时，才可使用 `{"config":{"exporType":"EXCEL","exportRows":0,"paramsInfo":{}}}` 请求完整导出，不照搬旧脚本的 -1。`paramsInfo` 的键和值结构同样按当前契约构造；若契约规定键为参数 alias、值对象使用 `values`/`displayValues`，也只有契约明确空对象沿用报表默认值时才能如此解释，不能自行认定为空筛选或清空筛选。
- 目录 `type` 与接口返回的报表类型可能不同：已见目录 `COMBINED_QUERY` 对应元数据 `DETAILED_QUERY`，目录 `INSIGHT` 对应元数据 `AD_HOC_ANALYSIS`。因此，不要把目录 `type` 机械填入可选的 `resourceType`；这会让本来只凭 ID 可成功的请求报 `REPORT_NOT_EXIST` 或 `OBJECT_NOT_FOUND_ERROR`。只有当前契约要求类型或 ID-only 请求确实失败时，才核实同一节点的 `extendedType` 并按已证实的类型有限重试，不逐类型枚举。目录存在、元数据失败或默认导出只有表头，均不能据此断言资源不存在或业务数据为空。
- 导出工作表名称可能与表内指标标题不同；按实际表头、数据及已核实组件口径回答，不仅按页签名命名指标。

AIChat 内部的 `smartbi_cli`、注入式凭证和沙箱工具不等于桌面的 `@smartbi/cli`。不能复制内部凭证文件、固定脚本路径或旧版命令来宣称通用支持。具体接口、资源类型和 Skill 标识以目标部署核验为准；每种报表类型、参数组合和业务数值都按实际结果独立校验。
