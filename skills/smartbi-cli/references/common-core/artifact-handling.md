# 文件交付与解析

模型、报表或白泽交付文件时，按实际接口下载并读取校验 Excel、CSV 或 Parquet；不能把服务端 URI 当作本地路径，也不能把预览表当作完整导出。不要暴露签名 URL。公共工具 `scripts/common-core/artifact_io.py` 支持文件读取；处理白泽文件事件时，还可检查已捕获的 SSE 流，并通过当前 SmartBI 配置下载文件。

同一读取脚本也能检查直接取数下载的文件。CSV 值应先保留为文本，包括前导零、小数文本及字面量 `NA`／`NULL`；空单元格保持空字符串。Excel 保留存储的单元格类型，Parquet 以 schema 为准。计算前依据模型元数据显式转换数值度量，标识列保持原值。仅凭 CSV 无法区分空字符串与导出空值；Excel 数字格式也可能显示存储值中不存在的零。不要补造标识符位数或空值语义。
